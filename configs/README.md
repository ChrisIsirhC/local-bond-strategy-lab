# 策略配置目录说明

## 正式策略

网页的“基线配置”只读取 `configs/` 根目录中的JSON。目前保留四个具有明确研究含义的版本：

1. `策略01_V1初始_原始权重_中性0.5.json`：最初版权重和仓位，用于观察V1基础效果。
2. `策略02_最佳权重_中性0.5.json`：只优化权重，仓位仍保持初始设置。
3. `策略03_最佳权重_中性0.8.json`：在最佳权重基础上提高中性仓位。
4. `策略04_最佳权重_中性1.0.json`：除看空外始终满仓，用于减少低仓少吃carry。

策略名称和JSON文件名均使用中文。网页另存新配置时，同名文件不会覆盖，而会增加序号。

## 历史配置

`configs/archive/` 保存此前重复或命名不清楚的英文JSON。它们不在网页下拉框中显示，但保留用于追溯旧结果。

## 实验配置

`configs/experiments/` 保存尚未提升为正式策略的研究配置，例如阈值搜索基线和阈值搜索最优结果。实验结论经过更长历史数据或滚动样本外验证后，再复制为正式中文策略。

## 配置与运行记录

JSON只定义策略参数。每次网页运行的实际配置、数据版本、代码版本和结果统一保存在：

```text
backtest_outputs/experiments/
```

不要根据文件修改时间猜测报告对应哪套参数，应查看实验目录中的 `config.json` 和 `run_manifest.json`。
