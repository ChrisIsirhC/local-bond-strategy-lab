# 10Y地方债标的/基准原始数据

## 文件

- 地方政府债到期收益率_10年_2024至最新.csv

## Choice 指标口径

- 指标 ID：E1704597
- 指标名称：地方政府债到期收益率:10年
- 单位：%
- 来源：中证指数公司
- 地区：中国
- 频率：1
- Choice 元数据起点：2016-11-14
- Choice 元数据终点：2026-07-10
- Choice 更新时间：2026-07-10

## 字段说明

- 日期：交易/指标日期。
- 到期收益率_百分比：原始收益率，单位为 %。
- 到期收益率_小数：百分比收益率除以 100，用于后续收益计算。
- 收益率日变化_BP：相邻可得日期之间的收益率变化，单位 bp。
- 数据来源：Choice 指标及来源说明。
- 更新时间：本文件生成时间。

## 重要限制

原计划提取 2020 至今数据，但当前 Choice API 对该宏观/EDB 序列返回权限限制：试用版API仅支持提取近3年的宏观数据。实际测试中 2023-07 起始仍被拒绝，2024-01-01 起始可成功返回，因此本次只落盘 2024 至最新可得日期的数据。

后续如果账号权限放开，可用同一指标 ID E1704597 重新提取 2020 至今，并覆盖/另存更长窗口文件。

## 后续接入

本文件只保存收益率曲线原始数据，不计算债券总收益。回测框架中应基于 到期收益率_小数 和久期假设构造 carry + duration PnL 的10Y地方债合成总收益，并将 100% 长期持有作为主基准。
