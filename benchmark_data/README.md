# 10Y国债与地方债收益率曲线

## 当前回测文件

- `地方政府债到期收益率_10年_2020至最新.csv`：策略交易标的，同时可选作比较基准。
- `中债国债到期收益率_10年_2020至最新.csv`：可选比较基准。
- `10Y国债地债YTM_清洗后.csv`：两条曲线及地方债-国债利差的合并审计表。
- `10Y国债地债YTM.xlsx`：Choice 导出的原始工作簿，保留不改。

三份派生 CSV 均由项目根目录的 `prepare_benchmark_curves.py` 生成。

## 数据口径

- 来源工作表：`10Y国债地债YTM.xlsx` 的 `Sheet1`。
- 中债国债到期收益率:10年：单位为 `%`。
- 地方政府债到期收益率:10年：单位为 `%`。
- 当前清洗后覆盖：2020-01-02 至 2026-07-14，共 1,581 行。
- 标准曲线同时保存百分比、小数和相邻有效观测日变化 BP。

## 清洗规则

1. 日期统一解析为日期类型，收益率统一解析为数值。
2. 日期、国债 YTM 或地方债 YTM 任一缺失时删除整行。
3. 任一 YTM 小于等于 0 时视为无效观测并删除整行。
4. 原始地方债列共有 47 个 0 值，主要位于周末或节假日，已整行剔除，不进行前值填充。
5. 日期重复时保留最后一条，最终按日期升序排列。
6. 若清洗后任一曲线出现单个有效观测日超过 50BP 的跳变，脚本直接报错并要求人工核验。

不能把 0 值直接用于久期收益计算，否则会产生“正常 YTM -> 0 -> 正常 YTM”的两次虚假极端资本利得。

## 回测用法

- 策略交易标的固定为 10Y地方政府债合成收益，策略资本利得由地方债 YTM 变化计算。
- App 可选择 `10Y地方政府债` 或 `10Y国债` 作为比较基准。
- 基准选择只影响基准收益、超额收益和相对评价，不改变策略自身交易收益。
- 旧配置 JSON 没有 `benchmark` 字段时，默认使用 `local_gov_10y`，保持历史兼容。

## 标准曲线字段

- `日期`
- `到期收益率_百分比`
- `到期收益率_小数`
- `收益率日变化_BP`
- `数据来源`
- `更新时间`
