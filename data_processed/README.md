# 地方债 raw_data 二次处理说明

本目录由 `process_raw_local_bond.py` 从 `raw_data` 重新生成。

## 文件说明

- `图表指标_周度宽表_统一日期.csv`：主表，按截图看板整理为周度数据，所有看板指标均有值。
- `图表指标_周度宽表_全日期.csv`：保留所有供给周；银行/利差采用周期起始日前最近可用交易日，但主表不单列取数日期。
- `图表指标_日度宽表_统一日期.csv`：日度策略主表，所有看板指标均有值，且只使用信号日前可见数据。
- `图表指标_日度宽表_全日期.csv`：保留全部利差交易日，尚未具备完整指标的日期保留为空。
- `计算明细_供给_日度.csv`：来自 `未来一周发行_日度` 的日度供给及1年历史分位数。
- `图表指标_长表.csv`：按图中大类和中文指标名整理，适合统一读取和画图。
- `计算明细_银行过去一周净买入金额_日度.csv`：银行需求日度底层，包含大型银行、中小型银行、大中小银行净买入及5个交易日累计值。
- `计算明细_利差_日度.csv`：利差日度计算底层。
- `计算明细_基煜纯债基金净申购_日度.csv`：非银情绪日度底层。
- `最新可用指标快照.csv`：每个指标的最新可用日期和值。
- `缺失值和缺失指标说明.json`：仍缺失指标、中间缺失和处理原则。

## 关键处理口径

- 10年好地区一般债收益率来自 `时间序列_2026-07-10.csv`，逐日采用新券优先、老券回退；来源保存在 `计算明细_利差_日度.csv` 的 `利率数据来源` 字段。
- 10年国债活跃券收益率优先来自 `10年国债活跃券收益率_RQData_2020至今.csv`，缺失时回退 Choice EDB；1年国股行NCD利率优先来自 `1年NCD_中债商业银行同业存单到期收益率(AAA)1年_自2020.csv`，字段为 `中债商业银行同业存单到期收益率(AAA):1年`。若文件不存在，脚本依次回退旧 Choice 文件和 `地方债利差数据(1).xlsx`。
- `10年好地区一般债-10年国债活跃券利差` 和 `10年好地区一般债-1年国股行NCD利差` 均重新计算，未使用利差表中原有地方债收益率或原有利差列。
- 主表第一列 `信号日期` 等于该看板周周一；若周一为法定节假日，回测执行日可用交易日历顺延，但信号计算只使用该日期之前可见的数据。
- 周度看板中，银行需求和利差按每个供给周 `周期起始` 之前的最近可用交易日匹配；例如周一看板使用前一交易日数据。匹配日期不放主表，保留在计算明细和脚本逻辑中。
- `银行过去一周净买入金额` 优先使用 `银行净买入.csv` 中大中小银行每日净买入的向前5个交易日累计值；若新文件不存在，才回退到 `local_gov_percentile_series_20260703.csv` 的10Y、大行中小行、5日口径。若自然周只有2个交易日，该字段仍是向前5个交易日，不是自然周内2天求和。
- `基煜纯债基金周度净申购情况` 在主表中使用信号日前一完整周的数据，避免使用当周未来数据。
- 供给和利差的 `1年内滚动分位数` 使用当前观测日前365天内、且早于当前观测日的历史值，不使用当天或未来数据；银行需求仍保留原始 `3M/1Y滚动分位数` 字段。
- `上述利差周度变化情况` 等于本周信号日可见利差快照减上一周信号日可见利差快照，不是周平均值。
- 日度主表沿用字段名 `上述利差周度变化情况`，其日频口径为信号日前最近可用利差相对5个交易日前的变化。
- `过去一周是否有地方债“发飞”` 仅在原始表明确填写时标记为“是”或“否”，其余日期标记为“未知”；当前回测和参数搜索固定忽略该因子。
- 空值不做插值；前端连续空值剔除，中间空值保留并列示。
